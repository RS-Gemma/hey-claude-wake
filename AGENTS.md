# Agent instructions

Before changing this project:
1. Follow the global protocols at https://github.com/pistolwhip-justin/development-protocols-n-assets/blob/main/DEVELOPMENT_PROTOCOLS.md.
2. Follow this repository's docs/DEVELOPMENT_PLAN.md and docs/RELEASE.md.
3. Preserve scope and phase gates. Do not silently add features.
4. Distinguish planned, implemented, built, tested, verified, and documented.
5. Do not claim Android-device behavior has been verified unless it was tested on a physical device.
6. Do not commit APKs to the source tree. APKs belong in versioned GitHub Releases.
7. Do not replace or overwrite an existing release. Follow the release workflow's safe/idempotent checks.
8. Keep credentials and private material out of the repository.
